# 🖼️ Galeria de Imagens com Azure Blob Storage & Streamlit
Projeto prático desenvolvido em Python para demonstrar a integração de uma aplicação web com o **Azure Blob Storage**, cobrindo o ciclo completo de gerenciamento de arquivos na nuvem: upload, listagem e download.

## 🎯 Objetivo
Desenvolver uma aplicação minimalista que consome os serviços de *Object Storage* do Microsoft Azure via chave de acesso, permitindo:
* **Upload:** Envio de imagens locais (PNG, JPG, JPEG) para a nuvem.
* **Listagem:** Recuperação e exibição visual dos arquivos armazenados em formato de galeria em grade.
* **Download:** Download direto dos arquivos armazenados em sua resolução original.

## 💡 Tecnologias Utilizadas

* **Python**
* **Streamlit:** Framework para criação de interfaces web interativas.
* **Azure Storage Blob SDK (`azure-storage-blob`):** Biblioteca oficial para conexão com o Azure.
* **Pillow (PIL):** Processamento e leitura de imagens na interface.
